## 2025-10-27 - Standardizing Destructive Actions on Dashboard
**Learning:** Standardizing destructive actions (like project deletion) using a centralized `ConfirmModal` instead of inline buttons improves UI consistency and accessibility. It prevents accidental deletions and provides a clear, high-contrast warning for irreversible actions.
**Action:** Always prefer the centralized `ConfirmModal` for any destructive operation, ensuring the 'danger' variant and appropriate icons are used to signal risk.
